sam2-lite - efficient video segmentation

Made SAM 2.1 video tracking 2.1× faster on CPU. Distilled the image encoder into MobileNetV4, then - after profiling showed memory attention took 80% of each frame - distilled it to attend to 3 memory frames instead of 7. 2026retrieval · agents · eval

arXiv RAG - cited answers and a self-correcting agent

Hybrid retrieval (dense bge + BM25 fused with reciprocal rank fusion, then a cross-encoder reranker) and a local LLM that answers only from cited sources, or abstains. A LangGraph corrective-RAG agent fetches and indexes new arXiv papers when the index can’t answer. Evaluated on 200 questions with 95% bootstrap confidence intervals; served via FastAPI, a streaming Streamlit UI and Docker Compose.
